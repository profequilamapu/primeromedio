🎯 ¿Qué vamos a aprender hoy?

El álgebra es la "matemática de las letras". Vamos a usar letras (como x, y, m) para representar números que todavía no conocemos o que pueden cambiar.

📐 ¿Qué es un término algebraico?

Definición

Es una relación entre números, letras, símbolos y potencias, donde solo intervienen multiplicaciones y divisiones. No intervienen sumas ni restas dentro del término.

🤝 ¿Cuándo dos términos son semejantes?

Regla de oro

Dos términos son semejantes cuando tienen EXACTAMENTE el mismo factor literal (mismas letras y mismos exponentes). El coeficiente y el signo no importan.

✓ SÍ son semejantes

  • 3x2 y −7x2
  • −y y 9y
  • 5a2b y −2a2b
  • −4m3 y m3

✗ NO son semejantes

  • 3x2 y 3x3 (distinto exp.)
  • 5x y 5y (distinta letra)
  • 2ab y 2a (falta b)
  • −x2y y −xy2 (exp. diferentes)

➕ La regla mágica de la reducción

Regla

Para reducir términos semejantes, sumamos o restamos los coeficientes y conservamos el factor literal igual.

axn + bxn = (a + b)xn

📋 Ejemplos guiados

#OperaciónPensamientoResultado
15x + 3x5 + 3 = 88x
29y² − 4y²9 − 4 = 55y²
3−6m + 2m−6 + 2 = −4−4m
47a²b − 7a²b7 − 7 = 00
5−x − 5x−1 − 5 = −6−6x
63x + 5yNO son semejantes3x + 5y
⚠ Atención: Si los términos NO son semejantes, NO se pueden reducir. Se dejan tal cual.

✖ Las 3 reglas para multiplicar

Paso 1

Multiplicar SIGNOS

+ por + = +
− por − = +
+ por − = −

Paso 2

Multiplicar COEFICIENTES

Multiplicación normal de números.

Paso 3

SUMAR exponentes

Solo si la base es la misma:
xm · xn = xm+n

📋 Ejemplos resueltos

#OperaciónCálculoResultado
1(x²)(x3)2 + 3 = 5x5
2(x3)(x4)3 + 4 = 7x7
3(2x²)(3x3)2·3 = 6 ; 2+3 = 56x5
4(−4x)(2x²)−·+ = − ; 4·2 = 8−8x3
5(−5y)(−3y)−·− = + ; 5·3 = 1515y²

💡 Truco mental: primero el signo, luego los números, luego las letras. ¡Siempre en ese orden!
